# Photos des chevaux

Dépose ici les photos des chevaux de l'écurie (formats .jpg/.png).

Une fois la photo ajoutée dans ce dossier sur GitHub, récupère son URL
("Copier le lien de l'image brute" / "Raw" sur GitHub, ou simplement le
chemin relatif `assets/chevaux/nom-du-fichier.jpg`) et colle-le dans le
champ "Photo" de la fiche du cheval, depuis l'espace admin (onglet
"Chevaux").
